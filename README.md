## AI 검색 최적화 적용 내용

- **구조화 데이터(JSON-LD)** — `LocalBusiness`/`HomeAndConstructionBusiness`, `Service`, `OfferCatalog`,
  `FAQPage`, `HowTo`, `Article`, `ItemList`, `BreadcrumbList`
- **llms.txt** — 업체 정보, 서비스, 비용, 절차를 AI가 파싱하기 쉬운 마크다운으로 정리
- **AI 크롤러 허용** — GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended 등 명시적 Allow
- **답변 가능한 문장 구조** — 질문형 제목 + 단답형 첫 문장, 비교표와 수치 중심 서술
- **시맨틱 HTML** — 문서당 `h1` 1개, 논리적 heading 계층, `table`+`caption`, `details` FAQ

## 견적 문의를 문자로 받기

정적 사이트에는 서버가 없어 사이트가 직접 문자를 발송할 수 없습니다.
현재는 **방문자의 문자 앱을 여는 방식**으로 구현되어 있습니다.

- 견적 폼을 채우고 `문자로 보내기`를 누르면 방문자의 문자 앱이 열리고
  010-6269-6193 수신, 본문에 입력 내용이 자동으로 채워집니다. 방문자는 전송만 누르면 됩니다.
- iOS는 `sms:번호&body=`, 안드로이드는 `sms:번호?body=` 규격을 써서 `js/contact.js`에서 분기합니다.
- PC에서는 문자 앱이 열리지 않으므로 `메일로 보내기` 버튼과 전화번호를 함께 노출합니다.

### 방문자 조작 없이 자동으로 문자를 받으려면

문자 발송 API는 인증 키가 필요하고, 키를 웹페이지에 넣으면 누구나 훔쳐 쓸 수 있으므로
반드시 서버를 거쳐야 합니다. 무료 범위로 가능한 구성입니다.

1. 국내 문자 API 가입 — 알리고, 솔라피(쿨SMS), NHN Cloud 등 (건당 과금, 발신번호 사전 등록 필요)
2. Cloudflare Workers 또는 Vercel Functions에 발송 함수 배포 (무료 플랜으로 충분)
3. API 키는 해당 서비스의 환경변수에 저장 — 절대 이 저장소에 넣지 않습니다
4. `js/contact.js`가 그 함수 주소로 폼 내용을 POST하도록 변경

키만 발급받아 알려주시면 나머지는 설정해 드릴 수 있습니다.
카카오톡 채널 상담을 붙이는 방법도 있습니다 (무료, 알림톡은 별도 비용).
