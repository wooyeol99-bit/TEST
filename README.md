## AI 검색 최적화 적용 내용

- **구조화 데이터(JSON-LD)** — `LocalBusiness`/`HomeAndConstructionBusiness`, `Service`, `OfferCatalog`,
  `FAQPage`, `HowTo`, `Article`, `ItemList`, `BreadcrumbList`
- **llms.txt** — 업체 정보, 서비스, 비용, 절차를 AI가 파싱하기 쉬운 마크다운으로 정리
- **AI 크롤러 허용** — GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended 등 명시적 Allow
- **답변 가능한 문장 구조** — 질문형 제목 + 단답형 첫 문장, 비교표와 수치 중심 서술
- **시맨틱 HTML** — 문서당 `h1` 1개, 논리적 heading 계층, `table`+`caption`, `details` FAQ
- **요약 먼저, 설명은 접기** — 긴 설명은 `<details class="more">`로 접어 화면에서는 요약만 보이게 하고,
  본문은 HTML에 그대로 남겨 크롤러가 전부 읽도록 했습니다 (아래 참고)

## 설명 글을 접어 두는 방식 (`.more`)

AI 검색용 사이트라 정보량은 많아야 하는데, 사람이 보기에는 글이 길면 읽지 않습니다.
그래서 **요약은 항상 보이고 자세한 설명은 접어 두는** 방식을 썼습니다.

```html
<h2>강마루 시공</h2>
<p>합판 층 위에 전용 접착제를 도포해 붙이는 방식입니다. …</p>  <!-- 항상 보임 -->
<details class="more">
  <summary>적합한 공간 · 작업 범위 · 시공 기간</summary>
  <ul>…</ul>                                                  <!-- 눌러야 펼쳐짐 -->
</details>
```

`<details>` 안의 내용은 **화면에서만 접힐 뿐 HTML 소스에는 그대로 남습니다.**
GPTBot, ClaudeBot, PerplexityBot, Googlebot 모두 접힌 내용까지 읽습니다.
구조화 데이터(JSON-LD)와 `llms.txt`는 애초에 화면과 무관하므로 영향이 없습니다.

적용한 곳:

| 페이지 | 접은 내용 | 개수 |
|---|---|---|
| `services.html` | 자재별 적합 공간·작업 범위·시공 기간 | 8 |
| `colors.html` | 조합별 팁과 주의점, 규격·대리석마루 상세 | 10 |
| `guide.html` | 마루 층 구조, 견적 확인 8가지, 관리 요령 | 4 |
| `portfolio.html` | 바인더 작업 순서 4단계 | 1 |

첫 문장(= 질문에 대한 답)은 언제나 펼쳐진 상태로 둡니다. AI 검색은 이 첫 문장을 답변으로
인용하는 경우가 많기 때문에 여기를 접으면 안 됩니다.

## 견적 문의를 문자로 받기

정적 사이트에는 서버가 없어 사이트가 직접 문자를 발송할 수 없습니다.
현재는 **방문자의 문자 앱을 여는 방식**으로 구현되어 있습니다.

- 견적 폼을 채우고 `문자로 보내기`를 누르면 방문자의 문자 앱이 열리고
  010-6269-6193 수신, 본문에 입력 내용이 자동으로 채워집니다. 방문자는 전송만 누르면 됩니다.
- iOS는 `sms:번호&body=`, 안드로이드는 `sms:번호?body=` 규격을 써서 `js/contact.js`에서 분기합니다.
- PC에서는 문자 앱이 열리지 않으므로 `메일로 보내기` 버튼과 전화번호를 함께 노출합니다.

### 방문자 조작 없이 자동으로 문자를 받으려면

문자 발송 API는 인증 키가 필요하고, 키를 웹페이지에 넣으면 누구나 훔쳐 쓸 수 있으므로
반드시 서버를 거쳐야 합니다. 무료 범위로 가능한 구성입니다.

1. 국내 문자 API 가입 — 알리고, 솔라피(쿨SMS), NHN Cloud 등 (건당 과금, 발신번호 사전 등록 필요)
2. Cloudflare Workers 또는 Vercel Functions에 발송 함수 배포 (무료 플랜으로 충분)
3. API 키는 해당 서비스의 환경변수에 저장 — 절대 이 저장소에 넣지 않습니다
4. `js/contact.js`가 그 함수 주소로 폼 내용을 POST하도록 변경

키만 발급받아 알려주시면 나머지는 설정해 드릴 수 있습니다.
카카오톡 채널 상담을 붙이는 방법도 있습니다 (무료, 알림톡은 별도 비용).

| 건강 | 몸무게(견종별 적정 체중), 심장사상충약, 질병. 미접종·비만·불결이 겹치면 병에 걸립니다 |
| 미니게임 | 공 물어오기 · 노즈워크(컵 찾기) · 훈련 순서 — 코인을 벌고, 훈련 게임은 실제 훈련도도 올려줍니다 |
| 난이도 | **순한맛**(이별 없음) / **매운맛**(오래 방치하면 무지개다리) |

앱을 꺼 둔 동안에도 시간이 흐르기 때문에, 다시 열면 그사이 배가 고파졌거나 배변이 쌓여 있습니다.

## 그림은 어떻게 그렸나

사진이나 이미지 파일을 전혀 쓰지 않습니다. `game/js/dog.js`가 캔버스 위에

1. 견종·나이별 **해부학적 형태**(두개골·주둥이·귀·가슴·다리·꼬리)를 조립하고
2. 왼쪽 위 광원으로 **입체 음영**과 접히는 곳 그늘을 넣고
3. 밑색을 픽셀 단위로 읽어 **털을 수천 올 한 올씩** 그리고 (실루엣 바깥으로 삐져나온 잔털 포함)
4. 어두운 모색에는 **역광**을, 눈에는 홍채·동공·반사광을, 코에는 젖은 질감을 얹습니다.

덕분에 파일 용량이 작고 오프라인에서도 즉시 그려집니다. 같은 강아지는 항상 같은 털 결을 갖도록
견종·단계로 난수 씨앗을 고정했습니다.

실제 강아지의 발달 과정도 그림에 반영돼 있습니다.

- 신생아는 **눈이 감겨 있고 몸을 말고 엎드려** 있으며 **코가 분홍색**입니다 (자라면서 검어집니다)
- 진돗개·시바·코기처럼 귀가 서는 견종도 **새끼 때는 귀가 접혀** 있다가 생후 8~12주에 섭니다
- 새끼는 머리가 크고 다리가 짧으며 털이 더 보송보송합니다

## 안드로이드 APK로 설치하기

웹 주소 없이 **앱 파일(APK)** 로 설치하고 싶을 때를 위해 안드로이드 앱 껍데기를 넣어 뒀습니다.
`android/` 는 게임(`game/`)을 그대로 앱 안에 담아 웹뷰로 띄우는 최소한의 프로젝트입니다.

- **인터넷 권한이 없습니다.** 앱이 밖으로 아무것도 보내지 않고, 비행기 모드에서도 돌아갑니다.
- 게임 파일을 복사하지 않고 `../game` 을 그대로 assets 으로 가져다 씁니다. 게임을 고치면 APK도 같이 바뀝니다.

### 받는 곳

`game/` 이나 `android/` 가 바뀌면 GitHub Actions가 자동으로 APK를 만들어 `apk` 태그 릴리스에 올립니다.
휴대폰에서 아래 주소를 누르면 바로 내려받을 수 있습니다.

```
https://github.com/wooyeol99-bit/TEST/releases/latest/download/woorijip-gangaji.apk
```

설치할 때 **`출처를 알 수 없는 앱`** 허용이 한 번 필요합니다 (설정 → 앱 → 특별한 앱 접근 → 알 수 없는 앱 설치).

### 직접 빌드하려면

안드로이드 SDK가 있는 컴퓨터에서:

```bash
cd android
./gradlew assembleRelease
# android/app/build/outputs/apk/release/app-release.apk
```

`android/keystore/dogpet.jks` 는 **사이드로드 전용 서명키**입니다. 비밀번호가 저장소에 그대로 적혀 있어
플레이스토어 배포에는 쓸 수 없지만, 키가 고정돼 있어야 다음 버전을 **덮어쓰기로 설치**할 수 있습니다.
스토어에 올릴 일이 생기면 새 키를 만들어 `android/app/build.gradle` 의 `signingConfigs` 만 바꾸면 됩니다.

## 설치 (홈 화면에 추가)

| 기기 | 방법 |
|---|---|
| 안드로이드 크롬 | 주소창 오른쪽 ⋮ → **앱 설치** |
| 아이폰 사파리 | 공유 버튼 ⬆︎ → **홈 화면에 추가** |
| PC 크롬/엣지 | 주소창 오른쪽 설치 아이콘 |

게임 안 **≡ 메뉴 → 홈 화면 추가**에도 같은 안내가 있고, 설치 가능한 브라우저에서는 그 버튼이 곧바로 설치 창을 띄웁니다.
설치하면 전체 화면으로 열리고, 서비스워커가 앱 파일을 캐시해 **비행기 모드에서도** 돌아갑니다.

| `game/js/state.js` | 세이브 데이터와 시간 시뮬레이션 (오프라인 경과도 같은 코드로 처리) |

| `game/sw.js` | 서비스워커. 파일을 고친 뒤에는 `CACHE` 버전 문자열을 올려주세요 |

## 로컬 확인

```bash
python3 -m http.server 8000
# http://localhost:8000/game/
```

서비스워커는 `localhost`와 `https`에서만 동작합니다. 파일을 고쳤는데 화면이 그대로면
개발자도구 → Application → Service Workers에서 **Update on reload**를 켜세요.

## 밸런스 손보기

- `game/js/data.js`의 `RATES` — 시간당 포만감/기분/청결/체력 감소 속도
- `game/js/data.js`의 `TUNE` — 산책 쿨다운, 오프라인 상한, 출석 보너스, 이별까지 걸리는 시간
- `game/js/breeds.js`의 `STAGES[].exp` / `minAgeH` — 단계 진급에 필요한 성장치와 최소 나이
- `game/js/breeds.js`의 각 견종 `traits` — 활동량·미용·훈련성이 게임 난이도에 그대로 반영됩니다
